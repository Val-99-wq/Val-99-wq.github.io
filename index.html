# BARANGAY REGULAR DISCOUNTED
(STUDENT/SENIOR)

Fare Rules

  • Regular minimum fare: ₱14
  • Discounted minimum fare: ₱12
  • The first 4 barangay positions use the minimum fare.
  • After the first 4 positions, the fare increases by ₱2 per additional barangay.
  • The fare is calculated using the distance between the origin and destination.
  • Discounted fares are for students and senior citizens.
  • Only ₱20, ₱50, and ₱100 bills are available for payment.
  • Passengers can be from 1 to 5.
  • The fare is multiplied by the number of passengers.
Cash buttons add bills to the player's received cash. This makes it possible to give the correct sukli using the available denominations.
